# Del 1 – Linux

I denna del lär vi oss grunderna i Linux och hur man arbetar i terminalen för att administrera ett system.

Vi installerar Linux genom WSL och Ubuntu så att vi kan arbeta i en riktig Linux-miljö. Därefter lär vi oss grundläggande shell-kommandon och hur man navigerar i systemet.

Vi går igenom hur Linux filsystem är uppbyggt och hur olika mappar används i systemet. Efter det arbetar vi praktiskt med filer och mappar, till exempel skapa, kopiera, flytta och ta bort.

Vi lär oss också hur användare fungerar i Linux och hur man sätter rättigheter så att olika användare kan läsa, skriva eller köra filer.

Sedan installerar vi program och paket med hjälp av pakethanteraren apt och lär oss hur man uppdaterar systemet.

Vi arbetar också med tjänster i Linux och lär oss hur man startar, stoppar och kontrollerar services.

Till sist installerar och konfigurerar vi en SSH-server så att man kan ansluta till servern på ett säkert sätt.

## Innehåll

01-install-linux  
Installera Linux med WSL och Ubuntu.

02-shell-commands  
Grundläggande kommandon i terminalen.

03-filesystem  
Hur Linux filsystem är uppbyggt.

04-files-and-directories  
Arbeta med filer och mappar.

05-06-users-permissions  
Skapa användare och hantera rättigheter.

07-packages  
Installera och uppdatera program med apt.

08-services  
Hantera tjänster i Linux med systemctl.

09-server-ssh  
Installera och konfigurera SSH-server.

## Mål

Efter denna del ska man kunna:

- arbeta i Linux-terminalen  
- navigera i filsystemet  
- hantera filer och mappar  
- skapa användare och sätta rättigheter  
- installera program och paket  
- hantera tjänster  
- konfigurera en server och SSH
