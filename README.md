# Linux Infrastructure Cloud Security

Detta projekt är en praktisk kurs där vi steg för steg bygger upp kunskap inom:

- Linux
- Infrastruktur
- Cloud
- Security

Målet är att förstå hur man bygger, konfigurerar och säkrar en servermiljö från grunden.

Kursen fokuserar på praktiskt arbete i Linux där vi lär oss hur en riktig servermiljö fungerar.

---

# Kursstruktur

Kursen är uppdelad i fyra huvuddelar:

1. Linux
2. Infrastruktur
3. Cloud
4. Security

Varje del innehåller teori, kommandon, praktiska övningar och quiz.

---

# Del 1 – Linux

Här lär vi oss grunderna i Linux och hur man arbetar i terminalen.

1. Installera Linux (WSL och Ubuntu)
2. Shell och grundläggande kommandon
3. Linux filsystem
4. Filer och mappar
5. Användare
6. Rättigheter (permissions)
7. Program och paket
8. Tjänster
9. Server och SSH

Målet är att kunna navigera i Linux och administrera ett system.

---

# Del 2 – Infrastruktur

Här lär vi oss hur servrar och system byggs upp.

1. Nätverk
2. DNS
3. Webserver (Nginx eller Apache)
4. Databasserver
5. Virtualisering
6. Grundläggande serverarkitektur

Målet är att förstå hur infrastrukturen bakom en applikation fungerar.

---

# Del 3 – Cloud

Här flyttar vi infrastrukturen till molnet.

1. Introduktion till Cloud
2. Skapa virtuella servrar
3. Storage
4. Nätverk i Cloud
5. Deploya en server i Cloud

Exempelplattformar:

- AWS
- Azure

---

# Del 4 – Security

Här säkrar vi servern och infrastrukturen.

1. Användarkontroll
2. SSH-säkerhet
3. Firewall
4. Loggning
5. Monitoring
6. Grundläggande säkerhetsprinciper

Målet är att förstå hur man skyddar en servermiljö.

---

# Praktiskt arbete

Under kursen bygger vi steg för steg en fungerande servermiljö där vi:

- installerar Linux
- konfigurerar systemet
- installerar tjänster
- kopplar upp servrar
- säkrar systemet

Allt arbete sker direkt i terminalen och dokumenteras i detta projekt.

## Bedömning

Bedömningen i kursen sker genom flera olika delar för att säkerställa att studenterna inte bara kan teori utan också kan arbeta praktiskt med systemen.

### Quiz

Quiz genomförs regelbundet under kursen och används för att:

- kontrollera att kunskapen sitter
- se om någon ligger efter
- identifiera vad som behöver repeteras
- testa förståelsen av momenten

Quiz är en del av bedömningen och hjälper både studenten och läraren att följa utvecklingen under kursens gång.

### Projekt

Under kursen arbetar studenterna även med praktiska projekt där de bygger och konfigurerar systemmiljöer.

Genom projekten ska studenten kunna visa att de:

- förstår vad de gör
- kan arbeta praktiskt i Linux
- kan bygga och konfigurera system
- kan förklara hur deras lösningar fungerar

### Aktivitet under kursen

En del av bedömningen baseras också på studentens aktivitet under undervisningen, till exempel:

- deltagande under lektioner
- arbete med övningar
- problemlösning
- samarbete och diskussioner

Syftet är att säkerställa att studenterna aktivt arbetar med momenten och utvecklar sin praktiska förståelse.
