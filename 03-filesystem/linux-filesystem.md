# Linux Filesystem

Linux använder ett hierarkiskt filsystem.

Alla filer och mappar i Linux börjar från **root-mappen**.

Den skrivs som:

/

Alla andra mappar ligger under denna.

---

## Root (/)

Root är den högsta nivån i Linux filsystem.

Exempel:

/

Härifrån når man alla andra mappar i systemet.

---

## /home

Här ligger användarnas mappar.

Exempel:

/home/delzar

Varje användare får sin egen mapp här.

Det är här man normalt arbetar och sparar sina filer.

---

## /etc

Här ligger systemets konfigurationsfiler.

Exempel:

- nätverksinställningar
- systeminställningar
- tjänstkonfigurationer

Systemadministratörer arbetar ofta i denna mapp.

---

## /var

Här lagras data som förändras under systemets drift.

Exempel:

- loggar
- cache
- databaser
- temporär data

---

## /usr

Här finns många av systemets program och bibliotek.

Exempel:

- installerade program
- systemverktyg

---

## /bin

Här ligger viktiga systemkommandon.

Exempel:

- ls
- cp
- mv
- rm

Detta är grundläggande kommandon som behövs för att Linux ska fungera.

---

## Sammanfattning

De viktigaste mapparna i Linux är:

/

home

etc

var

usr

bin

Att förstå filsystemet är viktigt för att kunna navigera och administrera ett Linux-system.
